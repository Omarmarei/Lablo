## Gotchas and lessons
**New in leg 158:**
- **A new default-on input mode breaks every e2e that types through DOM focus:** `e2e/tv-bundle.spec.ts` (real bundles; now types through the keyboard and clicks Done) and the engine walks (`tools/engines`: they pass `?keyboard=native`, four URL tests pinned it). Search for `index.html` URLs and `page.keyboard.type` when changing an input mode.
- **Keyboard widget rules:** in own mode OK on a key types it (so a test or walk can't end an edit with Enter: click the Done key, or send 65376); keys are heard on `document` in capture (Chromium 53 orders same-target listeners by registration, so a window listener would race `connectRemote`).
- **Playwright `hasText: 'Q'` is a case-insensitive substring:** use an exact regex for keys (`^Q$`).
- **An `OK` shortly after a pointer click is that click's twin** (`OK_CLICK_WINDOW_MS` 500 ms): wait it out in e2e before pressing OK after a click.
- **Unit tests for DOM-touching TV code in `packages/ui` run in node:** write a small fake document (`screen-keyboard.test.ts`); real-DOM behaviour goes in e2e.
- **Python heredoc patches with Arabic literals and no `-X utf8`:** the stdin script was decoded as cp1252 and the file read failed. Use `python -X utf8 -I -` and `encoding='utf-8', newline=''`, or the Edit tool for Arabic lines.
- **Mutation: redundant listeners give equivalent mutants** (a root and a button `mousedown`): drop one instead of testing both. Numbering shifts when entries are inserted mid-list; the script's `--check` finds stale snippets.
- **A background command with `&` inside a subshell reports "completed" at once:** wait on the log's `exit N` line.
- **`gh pr merge` can 502 yet merge:** check `gh pr view <n> --json state,mergeCommit` before retrying. After the merge, `git fetch` again before `git merge --ff-only origin/main`.
- **Core-js polyfill rule held:** the new files use `indexOf`, `slice`, `toUpperCase`, manual tokenizing (no `.split(`/`.includes(`/`.flat(` in shipped code).
